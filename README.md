# Volt Launcher — Project Shutdown Notice

This project has been permanently shut down. After extensive development and testing, we have encountered a large number of persistent bugs, stability problems, compatibility issues, performance regressions, and other technical challenges that could not be resolved in a maintainable way. These issues affected core functionality, the Android port, touch controls, modding support, rendering, and overall reliability across different devices and Minecraft versions. Continuing development on the current codebase was no longer viable.

The owner is now working on a new project called **Volt+**. Volt+ is a direct continuation of this effort, rebuilt from the ground up with lessons learned from the problems encountered here. It aims to deliver a more stable, better-architected native Rust Minecraft experience for Android while carrying forward the original goals of Vulkan rendering, modern touch controls, sandboxed mods, and a clean launcher experience.

Thank you to everyone who tried Volt Launcher, reported issues, and supported the project. All further development and announcements will move to Volt+.
